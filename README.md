Название: Diary# Diary_py Project

---

**О проекте:**

- Название: `Diary_py`
- Тип проекта: Личный дневник и менеджер заметок
- Цель: Создание платформы для записи мыслей, планов, заметок с удобным управлением

---

**Статус проекта:**

- ✅ Week 1 — Настройка проекта и базы данных
- ✅ Week 2 — Создание модели Note (заметки), миграции, регистрация в админке
- ⏳ Week 3 — Разработка CRUD API для заметок
- ⏳ Week 4 — Регистрация и логин пользователей, интерфейс
- ⏳ Week 5 — Работа с заметками, AI-ассистент, уведомления
- ⏳ Week 6 — Тестирование, оптимизация и презентация

---

**Стек технологий:**

- Python 3.13
- Django
- PostgreSQL
- Django Rest Framework
- HTMX / AJAX
- OpenAI API
- Telegram API

---

**Функционал проекта:**

- Создание, редактирование и удаление заметок
- Авторизация и регистрация пользователей
- Ограничение доступа по ролям
- Установка сроков и приоритетов заметок
- Прикрепление файлов к заметкам
- Интеграция AI для генерации описаний
- Email и Telegram-уведомления
- Drag & Drop заметок
- Аналитика и прогноз сроков
- Unit-тесты и API-тесты
- Генерация API-документации (Swagger / Redoc)

---

**Как запустить проект:**

1. Клонировать репозиторий:
   ```
   git clone https://github.com/Muyryoku/Diary_pyproject.git
   ```

2. Перейти в папку проекта:
   ```
   cd Diary_pyproject
   ```

3. Установить зависимости:
   ```
   pip install -r requirements.txt
   ```

4. Настроить файл `.env` с данными для базы данных.

5. Выполнить миграции:
   ```
   python manage.py migrate
   ```

6. Запустить сервер:
   ```
   python manage.py runserver
   ```
